Git & GitHub

Controle de Versão e Colaboração

O Problema

  • ❌ Caos nos arquivos: Versões espalhadas.
  • ❌ Medo de apagar: Sem backup do código.
  • ❌ Conflitos: Sobrescrever trabalho alheio.

O que é o Git?

É um Sistema de Controle de Versões Distribuído (DVCS).

Snapshot: Ele não salva apenas a mudança, mas o estado completo do projeto em um momento do tempo.

Conceitos Fundamentais

Commit: Um ponto de salvamento.

Branch: Uma ramificação do código.

Merge: A união de versões.

O que é o GitHub?

Plataforma de hospedagem para repositórios Git.

O "Facebook" dos programadores, onde você exibe seu código e colabora com o mundo.

Git vs. GitHub

Git GitHub
Software Local (Instalado) Serviço Online (Nuvem)
Gerencia o histórico Hospeda o histórico
Funciona offline Requer internet

Guia Rápido de Comandos

git init   # Iniciar repo
git clone [url]   # Copiar repo
git add .   # Preparar arquivos
git commit -m "msg"   # Salvar
git push   # Enviar para nuvem
git pull   # Atualizar local

Colaboração no GitHub

Fork: Copiar um projeto para si.
Pull Request: Sugerir melhorias ao autor.
Issues: Reportar bugs ou sugerir funções.
